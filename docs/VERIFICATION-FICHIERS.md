# Vérification du code après refonte

Les répertoires `frontend/src` et `backend/src` contiennent les applications actives, pas seulement une maquette ou un cahier des charges. Le frontend comprend des formulaires, des appels REST et les scènes animées ; le backend comprend les validations, contrôles d’accès, requêtes Supabase et générations de fichiers. Le schéma et les politiques sont versionnés sous `supabase/migrations`.

Les vérifications et réserves sont recensées dans `ETAT-DU-PROJET.md`. L’ancien prototype et ses documents sont conservés dans `archive/next-prototype` pour éviter toute perte de code utile pendant le changement d’architecture.
